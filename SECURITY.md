# Security policy

## Reporting a concern

Private vulnerability reporting is currently disabled, and the repository does not publish a verified private email address. To request a private channel, open a minimal public issue titled `Private report channel request`. Include no sensitive, vulnerability, or incident details in that issue. The repository owner can then establish a private channel for the report.

Once a private channel is established, include the affected file or workflow, a concise description, reproduction steps if safe to share, and the potential impact. Do not include credentials, access tokens, personal data, or unsafe hardware-control instructions in a public issue.

## Scope

This repository is a robot-description concept and does not provide a deployed service, authenticated endpoint, controller stack, or hardware interface. Reports about dependencies, launch configuration, path handling, or sensitive committed material are still welcome.

No response-time or remediation commitment is stated. Security reporting must not be interpreted as support for a physical robot or control deployment.
